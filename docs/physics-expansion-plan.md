# 추진·지상·비행 영역 확장 및 공식 시험 계획

2026-11-19 사용자 요청에 따른 **후속 계획**이다. 이번 문서 작성으로 구현·시험이 시작되거나 완료된 것은 아니다. 기준 구현은 [항법·물리 통합 결과](navigation-physics.md)이며, 기본 기체는 가상의 수납식 연구 구성이다. 기존 Thor와 고정기어 C208B 연구 파일을 회귀 기준으로 유지한다.

## 1. 목표와 완료의 의미

추진 정밀화·지상 물리 정밀화·비행 영역 확장을 같은 자체 비행역학에 연결하고, 선언한 운용 범위에서 프로젝트 공식 시험을 수행한다. 단순 화면 연출이나 유한 수치 계산을 실제 물리 검증으로 대신하지 않는다.

각 기능은 다음 세 상태를 따로 기록한다.

| 상태 | 필요한 근거 |
| --- | --- |
| 구현 완료 | 수식·단위·가정·입력/상태·API·표시·실패 처리가 연결됨 |
| 소프트웨어 공식 시험 합격 | 사전에 확정한 요구사항/시험 절차·수치 근거·시험 범위·허용오차에 따라 지정 버전을 시험하고 결함을 판정함 |
| 실기체 성능 대조 완료 | 동일 구성의 독립 시험 자료·오차 기준·불확도를 확보하고 대조함. 미확보 항목은 미검증/미판정으로 남김 |

이 계획에서 ‘정식 시험’의 기본 범위는 **프로젝트 소프트웨어 공식 적합성 시험**이다. 항공 인증이나 실기체 전체 성능 검증 완료를 의미하지 않는다. 연구 가정으로 기능 구현과 소프트웨어 시험을 진행할 수 있지만, 그 결과로 실기체 대조 칸을 합격 처리하지 않는다.

## 2. 진행 순서

| 단계 | 주요 작업 | 다음 단계로 넘어가는 조건 |
| --- | --- | --- |
| P0 | 자료·수식·운용 범위·시험 기준 확정, 현재 기준 기록 보존 | 요구사항/시험 ID, 출처/가정, 비교 자료와 판정 가능 여부가 추적됨 |
| P1 | 프로펠러 특성·가변 피치·거버너·풍차/페더/리버스 | 축 에너지·토크·추력 부호/응답과 기본 비행이 통과 |
| P2 | 후류·추진 비대칭 효과와 공중 제어 연결 | 동력/형상 변화에 따른 힘·모멘트·트림·항법 회귀 통과 |
| P3 | 착륙장치 완충·바퀴 회전/종·횡슬립·제동 | 평형·에너지·접지·제동·요철/경사 시험과 표시 일치 |
| P4 | 비대칭 실속·고받음각/스핀·버핏·연료/질량/CG | 선언한 영역의 수치/물리 검사, 상태/범위 공개와 정상 비행 회귀 통과 |
| P5 | 통합 운용 범위 시험과 제어기 보완 | 확대 시나리오에서 정상 완료 또는 요구된 복행/중단/거절 동작 |
| P6 | 버전 고정·공식 정적/동적/신뢰성 시험·보고서 | 필수 시험 판정, 결함 처리, 재시험/제약/미판정과 인수 문서 확정 |

공식 시험 체계는 P0부터 준비한다. P6에서 처음 시험 기준을 만드는 방식은 쓰지 않는다. 각 단계 안에서도 작은 기능 하나씩 **최소 구현 → 관련 검사 → 실제 API/표시 확인 → 기준 비교**를 끝낸다. 추진·접촉·공력 모델을 동시에 바꿔 원인을 구분할 수 없게 하지 않는다.

## 3. P0 — 기준·자료·시험 설계

### 자료와 기체 구성

- 엔진/프로펠러 형번, 피치 범위, 감속비, 회전 방향, 로터 관성, CT/CQ 또는 블레이드 형상/공력 자료를 조사한다.
- 기어 장착점·행정·하중/변위·감쇠, 타이어 반경/관성·마찰/슬립·브레이크 자료를 조사한다.
- 저속/플랩별 공력, 좌우 비대칭/고받음각·각속도 영향, 질량·CG·관성·연료 구성을 조사한다.
- 판본·구성·좌표축·단위·출처·사용 가능 범위를 기록한다. 다른 엔진/프로펠러나 EX/수상형 등의 수치를 혼합하지 않는다.
- 확보한 실측값·문헌의 계산값·개발 가정을 분리한다. 자료 부족 항목은 별도 연구값과 적용 범위를 선언하고 진행하되 실기체 정확도를 판정하지 않는다.

### 구현 전에 남길 기준

- 현재 프로필/소스/모듈 지문, 트림·종/횡 입력·협조 선회·엔진컷·활주/착륙·20km 왕복 기록을 기준으로 지정한다. 이미 있는 유효 기록은 재사용한다.
- 요구사항과 시험 ID를 연결하고 정상·경계·오류·고장 동작을 적는다. 물리 모델의 사용 범위와 자동운항 제어기가 지원하는 범위도 분리한다.
- 수치 허용오차는 해석해·독립 계산·입력 정밀도·시간/공간 간격 수렴에서 정한다. 실기체 오차는 독립 자료의 조건/불확도와 합의한 요구 수준에서 정한다.
- 구현 결과를 본 뒤 허용오차를 늘려 합격시키지 않는다. 근거가 없어 판정할 수 없는 항목은 시험 전에 미판정 대상으로 표시한다.

**산출물:** 구성/자료 목록, 요구사항–수식–코드–시험 추적표, 시험 절차 초안, 고정된 기준 기록과 허용오차 근거.

## 4. P1 — 프로펠러·거버너·역동력 상태

현재의 이차 부하 근사를 대체할 프로펠러 특성부터 만든다. 확보 가능한 CT/CQ–전진비–피치 자료를 우선 사용한다. 자료가 부족하면 분리된 연구용 특성 또는 자체 블레이드 요소/운동량 계산을 사용하며 실측 테이블로 표시하지 않는다. 외부 FDM 구현을 가져오지 않는다.

진행 순서:

1. 피치·회전수·유입 속도에 따른 추력/부하 토크와 유효 범위, 보간·영점·영역 밖 처리를 구현한다.
2. 프로펠러 피치 명령/실제 피치·변화율·기계적 한계를 상태로 둔다.
3. 목표 RPM을 유지하는 거버너를 연결한다. 엔진 동력 한계·피치 포화·과속·구동 상실에서의 포화/적분 처리를 확인한다.
4. 풍차 구동·페더·리버스를 차례로 연결한다. 음의 추력과 공기→로터 에너지 전달을 허용하되 부호/에너지 수지를 명확히 한다.
5. 엔진/프로펠러 트림과 자동항법·감속·복행을 재검사한다. 실제 기체에 해당 기능이 없는 구성은 지원하지 않는다고 공개한다.

스로틀, RPM 레버/거버너 목표, 피치/페더/리버스 제어의 관계를 먼저 정하고 동일한 물리 입력을 API·Python·UI에 제공한다. 리버스 허용 조건 등은 기체별 자료 또는 명시한 연구 운용 규칙으로 둔다.

**최소 검사:** 축 토크/회전 에너지 수지, 정지/전진/영유입의 유한 계산, 피치/추력/토크 부호, 거버너 계단·부하 변화·포화, 엔진컷 풍차·페더/리버스 전환, 간격 변화와 재현, 잘못된 특성 파일의 실패 보존.

**완료:** 정상/이상 상태를 포함한 새 추진 경로와 상태/계기/회전 표시가 일치한다. 실제 자료가 없는 경우 연구 모델 구현 합격과 실기체 성능 미판정을 함께 기록한다.

## 5. P2 — 후류·비대칭 추진 효과

- 먼저 축방향 유도 유동과 후류 영역/수축을 계산하고, 그 안의 날개·꼬리 위치에서 국소 유입을 평가한다.
- 후류에 들어간 면의 동압/받음각 변화를 힘·모멘트로 연결한다. 별도 ‘추가 양력’을 중복해서 더하지 않는다.
- 회전 후류·P-factor는 방향/적용 위치와 근거를 분리해 추가한다. 기존 축 반작용·자이로 모멘트와 중복 계산하지 않는다.
- 추력선·프로펠러 회전 방향·후류/면 배치를 프로필에서 추적할 수 있게 한다. 기체마다 같은 보정을 강제하지 않는다.
- 저속 고출력·피치/플랩 변화·이륙·복행에서 트림, 러더/에일러론 여유와 제어 포화를 다시 확인한다.

**최소 검사:** 무동력/후류 밖의 기준 복귀, 대칭 배치의 좌우 대칭, 회전 방향 반전의 부호, 면적/거리 변화, 힘/모멘트 합산, 동력 한계, 면 분할 간격 영향, 정상 순항/선회 회귀.

**완료:** 저속/고출력의 조종 효과가 같은 물리를 통해 나타나고, 계산한 유동·국소 공력·합력의 관계를 기록으로 설명할 수 있다. 모든 후류를 고정 배수로 대체하고 정밀 모델로 부르지 않는다.

## 6. P3 — 착륙장치·타이어·제동

이번 단계에는 완충 모델도 구현 대상으로 포함한다. 현재 강체 접촉은 기준/비교 모드로 남기고 새 모델을 독립적으로 시험한다.

1. 각 바퀴의 회전 관성·각속도·회전각, 스트럿 압축량/행정·속도, 법선/접선 반력을 명시한다.
2. 스프링·댐퍼·행정 끝단을 접촉 해법과 일관되게 연결한다. 기존 강체 반력에 완충력을 병렬로 더하지 않고, 중복 지지를 제거한다.
3. 타이어 종방향 슬립·횡슬립/슬립각과 마찰 한계를 결합한다. 정지·저속에서 속도로 나누는 특이점과 부호 반전을 처리한다.
4. 브레이크 토크·바퀴 잠김·재회전, 좌우 차등 제동을 연결하고 안티스키드 연구 모드를 별도로 추가한다.
5. 바퀴별 요철/경사/활주로 경계·지면 누락, 기어 잠금/수납 상태와 접촉을 함께 처리한다.
6. 표시 스트럿 압축·바퀴 회전·기어 위치를 계산 상태로 구동한다. 시각 효과만으로 튐을 숨기지 않는다.

마찰의 노면/속도 의존성은 기체/표면 자료 또는 명시한 연구값을 사용한다. 타이어 열·마모·파손의 정밀 모델은 이번 필수 범위에 넣지 않는다.

**최소 검사:** 정지 하중 분배, 스프링 정적 변위, 감쇠 자유응답·낙하 에너지, 행정 끝단, 자유 구름의 바퀴 속도/반경, 제동 에너지·잠김/회복, 마찰의 비양의 일, 차등 제동 요 모멘트, 요철/경사/누락, 접촉 간격 수렴, 정상/경착륙과 정지 후 침투/튐.

**완료:** 반력·압축·회전·슬립·제동·표시가 일치하고 에너지와 수치 수렴 기준을 충족한다. 실제 제동거리/최대 기어 하중을 자료 없이 합격 처리하지 않는다.

## 7. P4 — 비행 영역 확장

### P4a. 좌우 비대칭·고받음각

- 좌/우 날개와 필요한 면을 분리하고, 위치별 `V+Ω×r`·바람·후류로 국소 유입을 계산한다.
- 면별 박리/재부착 상태와 조종면 효과 저하를 연결해 비대칭 실속·윙드롭·큰 각속도 영향을 다룬다.
- 기존 전기체 미계수와 면별 모멘트가 중복되지 않도록 결합 방식을 명시한다. 작은 교란 영역에서는 기존 기준과 대조한다.
- 플랩/기어·출력·질량 조건별로 새 트림과 제어 여유를 확인한다. 받음각 부호/영유속/각도 경계의 연속성과 에너지 방향을 검사한다.

### P4b. 스핀·버핏

- 스핀은 비대칭 박리·요/롤·관성 결합으로 발생하도록 한다. 타이머로 기체 각속도나 위치를 직접 지정하지 않는다.
- 진입·발달·회복·회복 불가/영역 밖을 구분해 상태와 시험 기록으로 공개한다. 실제 기체 회복 절차/성능으로 보증하지 않는다.
- 버핏은 박리·동압과 연결한 반복 가능한 하중 변동으로 먼저 구현한다. seed/시간 정의를 남기고 렌더 프레임에 따라 달라지지 않게 한다. 단순 카메라 흔들림을 물리 버핏으로 부르지 않는다.
- 구조 공탄성·피로 수명·파손을 검증한 모델로 확대하지 않는다.

### P4c. 연료·질량·CG·관성

- 초기 연료/탑재 구성과 엔진 운용에 따른 연료 소모를 연결한다. 소모율의 출처/개발 가정을 기록한다.
- 질량·CG·관성·공력면/기어의 CG 기준 위치를 함께 갱신한다. CG 변경 때문에 표시 기체나 API 위치가 순간 이동하지 않도록 좌표 계약을 정한다.
- 기존 고정 질량 모드는 유지한다. 순간적인 탑재물 이동·연료 슬로싱은 별도 모델 없이는 지원하지 않는다.
- 연료 고갈·편중·질량/CG 경계의 운용 제한과 자동 운항의 반응을 확인한다.

**최소 검사:** 대칭 면의 힘/모멘트 상쇄, 비대칭 입력/회전 방향, 작은 교란 미계수, 박리/재부착 이력, 고받음각/큰 각속도 수렴, 스핀 진입/회복의 반복성, 버핏 재현/시간 간격 영향, 질량/CG/관성 독립 계산·양의 정부호·좌표 연속성·연료 고갈.

**완료:** 선언한 확장 영역을 수치/물리 검사로 설명하고 미검증 구간을 공개한다. 전 영역 표가 없으면 구현된 고받음각 모델과 실기체 검증된 영역을 구분한다. 모든 고정익·초음속/천음속까지 검증했다고 표현하지 않는다.

## 8. P5 — 운용 범위 확대·통합

한 번의 초기화 뒤 이륙→기어 수납→다중 임무/고도 변화→귀환→전개→접근/복행→접지·제동→주차를 실행한다. 추진·공력·접촉 변경에 맞춰 제어기/형상 전환을 조정하되 물리 계수를 항로 성공에 맞춰 임의 보정하지 않는다.

| 축 | 정상·경계·오류 시험 |
| --- | --- |
| 초기/목표 상태 | 선언한 속도·높이·질량/CG 범위의 대표점·경계·영역 밖 입력 |
| 환경 | 무풍·정면/측면/배풍·기존 경계·돌풍·새로 선언한 확장 경계 |
| 추진/형상 | 출력 변화·RPM/피치·페더/리버스 허용 조건·플랩·기어 전환 |
| 고장 | 엔진/거버너/피치·브레이크/안티스키드·조종면 고착. 단일 고장부터 원인이 겹치는 조합으로 확대 |
| 항법 | 가까운 측방/반대 기수·짧은/긴 다중 항로·CW/CCW·고도/속도 전환 |
| 지상/착륙 | 노면 마찰·경사/요철·활주로 경계·불안정 접근·복행·낮은/큰 접지 하중·지면 누락 |
| 실행/경계 | 명시적 step/배속·일시정지/재개·API 입력 오류·재읽기 실패·연결 끊김·상태 보존 |

전체 조합을 무작정 곱하지 않는다. 먼저 대표점/경계·단일 고장을 고정하고 상호작용이 큰 조합을 선정한다. 실패 기록을 보존하고, 새 성공 조건으로 대체하지 않는다. 경계 밖 고장은 비행 성공보다 **정의된 거절·정지·복행·실패 공개**가 요구 결과일 수 있다.

## 9. P6 — 공식 시험·인수

### 정적 시험

- 단위·좌표·부호·수식/데이터 출처, 상태 소유권·초기화·모델 간 격리를 검토한다.
- 입력 유한성/형식·배열 경계·관성/물리 제약·실패 보존·오류 전파를 확인한다.
- 컴파일 경고·적용 가능한 정적 분석, API 경로/클라이언트/UI/문서·버전 계약을 대조한다.

### 동적 시험

- 해석해·독립 계산, 시간/면 분할 간격 수렴, 결정성·seed, 에너지/힘·모멘트 수지를 확인한다.
- P1~P5 시나리오와 기존 Thor·고정기어/수납식 연구 모델의 회귀를 지정된 버전에서 실행한다.
- 기준 실패 사례를 반드시 포함하고, 합격/실패/미판정/미실행을 각각 기록한다.

### 신뢰성·운용 시험

- 반복 왕복·장시간 실행, 초기화/모델 교체 반복, 고장 주입/해제, 요청 중단·재연결을 시험한다.
- 메모리·핸들·처리시간·실제 배속·시험 시간 지연과 종료/복구 상태를 계측한다.
- 시험 시간·반복 횟수·자원 상한은 P0에서 사용 목표와 예비 측정으로 정한다. 짧은 개발 검사 통과를 장시간 신뢰성 합격으로 대체하지 않는다.

### 시험판 고정·결함 처리

- 시험할 소스/바이너리·프로필·맵·seed·초기 조건·간격·입력 순서와 허용오차를 고정한다.
- 시험 중 코드/데이터를 바꾸면 변경 이력과 영향 범위를 남기고 해당 시험/회귀를 다시 수행한다.
- 결과를 본 뒤 기준을 완화하지 않는다. 결함 수정·기준 오류 수정·검증 범위 변경을 구분한다.
- 인수 시 필수 항목의 실패/미실행을 해소한다. 자료 미확보의 성능 항목은 미판정으로 명시하고 그 기능의 검증 범위를 제한한다. 하나의 ‘전부 완료’ 표시로 덮지 않는다.

**최종 산출물:** 요구사항/시험 추적표, 데이터/가정 목록, 고정 시험판, 원본 기록·그래프·화면, 정적/동적/신뢰성 결과, 결함/재시험 이력, 실기체 대조 가능/미판정 목록, 공개 API/조작 매뉴얼, 알려진 한계와 재실행 절차.

## 10. 구현 경계와 작업 원칙

- 계산 코어는 Unreal·렌더 프레임·벽시계와 분리한 자체 C++로 유지한다. 외부 FDM을 가져오거나 감싸지 않는다.
- 프로필/자료는 수식에 필요한 만큼만 확장한다. 기체별 근거가 없는 값을 실제 값으로 자동 생성하지 않는다.
- 상태/입력·기어/피치/거버너·바퀴/완충·연료·모델 적용 범위를 명시적 API로 노출한다. 변경 시 Python·Web UI·기록기·매뉴얼을 함께 갱신한다.
- 코어 변경은 관련 독립 검사, Unreal 경계 변경은 빌드/API·표시 확인을 수행한다. 오류/변경/미해결 우려가 없으면 같은 검사를 무작정 반복하지 않는다.
- 컴퓨터/UI 자동화 중단 결정을 유지하며 명령행·API·네이티브 장면 캡처를 사용한다.
- 새 기체/King Air 쌍발·센서/FCC·전국 지도 확장·무기 물리·기어 도어/유압은 이번 필수 범위에 넣지 않는다.

실행 단계에서는 기존 사용자 승인 범위에서 계속 진행하고, 모델/범위 선택이나 공식 실기체 판정 기준처럼 결과를 바꾸는 결정만 사용자에게 요청한다. 이번 요청은 계획 수립이며 구현 착수 승인을 새로 추정하지 않는다.
