# C208B 연구 모델

2026-11-18 현재 기본 선택은 사용자 요청에 따른 [가상의 수납식 기어 파생 연구 구성](retractable-research.md)이다. 이 문서의 `c208b-research.json`은 원래 고정기어 연구 프로필이며 보존한다. 파생 구성은 실제 C208B 사양이 아니고 기존 시험 기록과도 구분한다.

2026-11-18: [연속 귀환·착륙 결과](return-landing-results.md)의 M0~M5 연구 범위를 추가했다. 실제 지형 왕복·참고 경로/단계 UI·플랩/접촉 치수에 맞춘 내장 형상, CG 아래 .05m 추력선 모멘트·트림, 조향/제동 지연·속도별 조향 보호를 연결했다. 바퀴 .32m·프로펠러 표시 반경1.3m와 추가 지상 수치는 모두 연구 가정이다. 선택 숫자11개의 단위/기본값은 [기체 파일 안내](aircraft-profile.md)를 따른다. 아래11월17일 기록과 구분하며 실제 성능 미검증은 유지한다.

2026-11-17 사용자 승인으로 관성·추진·저속 공력의 누락 자료를 **개발 가정으로 명시한 별도 모델**로 진행했다. `aircraft/c208b-research.json`의 `provenance`가 값별 근거와 가정을 기록한다. **실제 C208B 성능은 미검증**이며 최신 EX/PT6A-140 모델이 아니다. A2의 동일 구성 실측 자료 확보는 계속 미완료다.

[Lampton·Valasek 논문](https://vscl.tamu.edu/wp-content/uploads/sites/134/2017/07/JAST_icing.pdf)의 clean Table 1 계수 일부를 사용한다. 원문의 `-CLalpha-CD1=-4.53`을 CLalpha로 오독하지 않고 **CLalpha=4.5를 별도 가정**했다. core 식으로 옮길 때 `reference_pitch=.10/.78`, `lift_ref=.26+4.5*reference_pitch`로 설정하여 clean `CL=.26+4.5α+.54δe`, `Cm=.10-.78α-1.61δe`가 된다. 그 외 속도·각속도 항과 후실속 전환은 파일의 근거 구분을 따른다. 원문의 계산/추정 계수를 실측으로 표현하지 않는다.

추진은 `Tmax=min(m*a_static, η*P*min(1,ρ/1.225)/max(V,1))`, `T=Tmax*실제스로틀*출력잔존율`이다. 추진력은 CG를 통과하는 body +X에 적용한다. 이는 유효 동력 상한을 가진 단순 추력 모델이다. 실제 터보프롭 RPM/거버너·토크·후류·비대칭 P-factor·리버스·페더링은 구현하지 않았다. 날개·꼬리 모멘트와 엔진 응답을 실제 성능에 맞춰 식별한 모델이 아니다.

## 실행·조작

API가 실행 중이면 [Web UI](http://127.0.0.1:8765/)에서 **기체 파일 다시 읽기**를 누른다. 기체 선택은 정지 중 아래 파일로 바꾼다.

```powershell
# 프로젝트 루트 PowerShell
Set-Content aircraft/active.json '{"profile":"c208b-research.json"}' -Encoding utf8NoBOM
# Thor로 복귀: 위 파일 이름을 thor.json으로 변경한 뒤 다시 읽기
```

Web UI는 기체 경고·초기 조건·지원 상태·항로 속도를 표시한다. 수동 조종면/스로틀은 기존 슬라이더, 플랩은 각도 입력과 **플랩 적용**, 지상은 **지상 초기화**·조향·브레이크를 쓴다. C208B는 기어 수납을 거부한다. 항로 JSON은 해당 기체 TAS와 마지막 선회 반경을 사용해야 한다. 위치를 바꾸면 항로점 좌표도 확인한다.

제주 가상 시험 활주로(인덱스0)를 **2000×60m**로 확장했다. 실제 제주공항이나 실기체 활주로 요구 길이를 뜻하지 않는다. 자동 이륙 전 **지상 초기화**로 정렬하고, **자동 이륙**을 누른다. **착륙 시험 위치**는 접근 조건으로 명시적으로 초기화하는 개발 명령이다. 자동 착륙 준비/실행은 같은 계산 코어·작동기·접촉을 사용한다. 지형/장애물 회피는 없으므로 임의 지형의 귀환 경로 안전을 보장하지 않는다.

```python
from uavsim_client import UAVSimClient
sim = UAVSimClient()
sim.pause()
state = sim.reload_aircraft_profile()
assert state["airframe"]["id"] == "c208b-research-assumptions"
sim.set_flaps(10)
state = sim.step(1)  # 명령각과 실제각은 state["flaps"]에서 구분
sim.reset_on_ground()
sim.start_automatic_takeoff(speed_mps=55, climb_height_m=50)
sim.set_running(True)
# 착륙만 시험: pause -> prepare_landing_approach -> start_automatic_landing(approach_speed_mps=40)
```

API·오류·기체별 범위는 [API 매뉴얼](api-reference.md), v2 구성 필드는 [기체 파일 안내](aircraft-profile.md)를 따른다. 선택/재읽기는 공중 트림으로 초기화하고 이전 비행 위치·시간을 복원하지 않는다. 바람은 유지하고 돌풍·고장·자동조종·플랩·기어는 초기화한다. 내장 외형은 날개폭에 맞춘 **표시용 대체 형상**이며 C208B 실제 외형이 아니다. 기어 바닥 위치는 선택한 접촉점에 맞춘다. 별도 STL은 그 파일의 치수를 유지하며 플랩 부품을 자동 분리/표시하지 않는다.

## 개발 검사와 남은 범위

Release CTest 10개에 `research_checks`를 추가했다. 실제 JSON의 수치를 읽어 트림 잔차, 동력 상한/정지 추력, 엔진컷, 플랩 속도, 고정기어, 수동 종응답, 항로→대기, 돌풍 재현, 정지 반력, 평면 2km 활주로의 **이륙→귀환 착륙→주차**, 불안정 접근의 물리 복행, 엔진 고장 이륙 중단을 확인한다. 허용오차는 수치 평형/운항 제어의 개발 기준이며 실측 성능 허용오차가 아니다.

실제 API 검사 **149개 assertion 통과**(시간 진행별 무고장/무충돌 확인 포함), 복원 오류0건. 구성 필드 누락/추가·숫자 bool 오입력·잘못된 접촉 치수의 실패 보존, 단일/다중 항로·수동 해제도 확인했다. 실제 API 검사는 [하네스](../scripts/check-c208b-api.py)와 [결과](../artifacts/c208b-api-check.json)에 기록한다. 이 하네스는 선택 파일과 바람을 복원하고 공중 트림·정지로 끝난다. 원래 위치/시간은 복원하지 않으며 실행 중 실험에 사용하지 않는다. 실제 지형의 이륙과 별도 준비 위치에서의 착륙은 평면 코어의 연속 귀환 검사와 구별한다.

스포일러 연동, 좌우/상하 비대칭 조종면 한계, 프로펠러 토크·후류, 실측 타이어/완충, 연료/CG 이동, 착빙·스핀·공탄성, 실제 성능 대조와 정식 시험은 남겨 둔다. 브라우저 직접 조작/렌더 육안 확인은 사용자 결정에 따라 실행하지 않는다. C~F의 **연구 가정 범위** 진행과 원래 계획의 실기체 자료 기반 C2~E2 완료를 구분한다.

최종 인계: `aircraft/active.json`은 `c208b-research.json`, 적용 ID는 `c208b-research-assumptions`다. TAS65m/s·공중 트림·기어 전개·플랩0°·정지·fault 없음으로 확인했다. Thor의 기존 착륙 시험 위치 TAS18m/s도 실제 API에서 보존 확인했다. [최종 상태 기록](../artifacts/c208b-final-state.json). UI는 새로고침 후 사용한다.
