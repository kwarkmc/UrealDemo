기체 형상 · STL

형상 수신 대기

aircraft/visual.json에서 STL 원본 파일을 선택합니다. 일시정지 중 형상만 다시 읽으며 위치·시간·비행역학은 유지합니다. 일체형 STL의 조종면은 자동 분리되지 않으며, 기본 랜딩기어 표시 여부는 설정에서 선택합니다.

비행역학 개발 중비선형 공력·실속 개발 모델. 실제 기체의 전 비행영역을 검증한 모델은 아닙니다. 수동 입력은 자동항법을 해제합니다.

지상 입력 수신 대기

지상 시작은 가상 시험 활주로에 무추력·지상속도 0·주차 브레이크 상태로 배치하고 일시정지합니다. 수동 이륙 예제: 주차·일반 브레이크 해제 → 스로틀 100%·비행 재생 → TAS 11m/s 이상에서 엘리베이터 −6° → 이륙 후 당김을 줄이세요. 조향은 저속에서 사용하고 착지 후 추력을 줄이고 브레이크를 적용합니다. AGL은 무게중심의 지면 법선 방향 거리이며 수직 고도·바퀴 간격과 다릅니다. 반력은 접촉 계산 간격의 충격량/시간으로, 착륙장치의 최대 충격 하중이 아닙니다. 상세 안내: docs/ground-operations.md.

자동 이륙 · 착륙

수신 대기

—

첫 설정 활주로(인덱스 0)를 사용합니다. 지상 시작 후 자동 이륙은 활주로 위 50 m·TAS 19 m/s를 목표로 재생합니다. 자동 착륙은 현재 위치에서 TAS 18 m/s로 진입하며 준비 조건을 벗어나면 거부됩니다.

착륙 시험 위치는 기체를 활주로 시작점 600 m 뒤·60 m 위, TAS 18 m/s의 초기 조건으로 바꾸고 정지합니다. 이후 자동 착륙을 누르세요. 자동 이륙·착륙 버튼은 준비 성공 후 재생하며, 외부 API는 준비와 시간 진행을 별도로 제어할 수 있습니다. 이륙 완료 후에는 고도를 유지하고, 착륙 완료 후에는 주차 브레이크·일시정지 상태가 됩니다. 개발용 제어기로 임의 조건의 성공을 보장하지 않습니다.

바람 · 실속 시험

적용 바람 수신 대기

바람은 ENU 속도 성분입니다. 양수는 각각 동쪽·북쪽·위쪽으로 부는 바람이며, 각 성분의 범위는 ±30 m/s입니다.

실속 시험 준비는 현재 위치·고도·방위에서 TAS 9 m/s, 받음각·피치 18°, 옆미끄럼·롤 0°, 조종면 중립·스로틀 0, 배속 1로 설정하고 정지합니다. 비행 재생을 눌러 변화를 확인하세요. 유동 박리 비율은 0~1의 연속값입니다.

이 개발 모델에서 회복을 살펴보려면 엘리베이터 양수(후연 아래)로 받음각을 줄이고 스로틀을 올리세요. 받음각이 줄면 기수 하강 입력을 풀고 자세를 회복합니다. 자동항법 중에는 실속 회복 제어가 고도 유지보다 우선합니다.

돌풍

돌풍 수신 대기

유효 바람 수신 대기

현재 시뮬레이션 시간에서 지연 후 시작하는 ENU 돌풍입니다. 세 방향의 최대 성분은 ±15 m/s이며 일정 바람에 더해집니다. 일시정지 중에는 시간이 진행되지 않습니다.

추진 · 조종면 고장

고장 설정 수신 대기

엔진 출력 비율 1은 정상, 0은 추력 상실입니다. 조종면 고착과 작동기 응답은 조종 입력 패널의 실제 출력에서 확인하세요. 고장 해제는 비행 상태를 초기화하지 않습니다.

항로점 자동항법

수신 대기

항로점 1~64개를 순서대로 통과한 뒤 마지막 지점을 선회합니다. 고도는 WGS84 타원체고(m), 속도는 대기속도(m/s)입니다.

속도 범위 16~24 m/s. 반경은 최대 뱅크각 30° 조건도 만족해야 합니다. 일시정지 상태에서 항로를 적용했다면 비행 재생을 누르세요.

print(sim.get_state())
